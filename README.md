# Bonjour chérie

Preuve de concept visuelle pour GitHub Pages — une page unique, interactive et soignée.

## Contenu

- Accueil avec animation « Bonjour chérie »
- Navigation latérale (style Cursor / Twitter)
- Sections Capacités, Démo, Design, À propos
- Thème sombre, glassmorphism, mesh animé

## Déploiement

Aucun build requis. Poussez le contenu de ce dossier à la racine d’un dépôt GitHub, puis activez **GitHub Pages** (branche `main`, dossier `/`).

Pour un site projet : `https://USERNAME.github.io/bonjour-cherie/`

Le fichier `.nojekyll` désactive le traitement Jekyll.

## Stack

HTML · CSS · JavaScript vanilla · Google Fonts (Instrument Serif + Outfit)
